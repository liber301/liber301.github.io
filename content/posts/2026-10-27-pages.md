这是一篇入门示例，记录这个博客的发布方式。

## 从 Markdown 到网页

文章保存在 `content/posts/`。构建脚本将文章、模板和样式组合成静态网页，同时生成归档、标签和搜索索引。

在项目目录里运行：

```bash
npm run build
npm run check
npm run preview
```

浏览器打开终端显示的本地地址，就能预览博客。

## 推送后自动更新

确认内容和页面效果后，提交并推送：

```bash
git add .
git commit -m "更新博客"
git push origin main
```

GitHub Actions 自动构建、检查并部署到 GitHub Pages。工作流显示成功后，打开 [博客首页](/) 查看更新。

## 一个简单的登录入口

博客入口增加了账号密码界面，文章直链也会先跳转到登录页。账号和密码摘要在代码配置中管理，无需额外账号平台。

这只是浏览器里的界面门槛。GitHub Pages 上的源码和静态文件仍然公开，不能用它保护秘密资料，也不要复用其他服务的密码。

## 继续慢慢写

本地写作，预览确认，再提交发布。把流程留得简单一些，才能把更多时间放在记录本身。
